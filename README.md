Uma plataforma web interativa desenvolvida para promover e facilitar a exploração do turismo no estado do Rio de Janeiro, reunindo atrações, 
roteiros e experiências locais em um só lugar.

O Turis Rio foi idealizado para centralizar e simplificar a busca por atrações turísticas em todo o estado do Rio de Janeiro. 
A proposta é oferecer tanto a turistas quanto a moradores um guia digital acessível, intuitivo e moderno. O projeto busca incentivar a exploração cultural e natural da região, organizando informações sobre praias, 
ecoturismo, patrimônios históricos e polos gastronômicos.

Front-end: HTML5 para a estruturação semântica da página, CSS3 para a estilização e layout responsivo, e JavaScript para a interatividade e dinamismo das funcionalidades.

Ambiente de Desenvolvimento: Visual Studio Code.

Controle de Versão e Hospedagem: Git e GitHub para versionamento de código, com deploy realizado via GitHub Pages ou Vercel.
